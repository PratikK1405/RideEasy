# 🚴 RideEasy - Bike Rental Web Application

A complete, modern bike rental management system built with HTML, CSS, JavaScript, PHP, and MySQL.

## ✨ Features

### User Features

- 🏠 Beautiful homepage with hero section
- 🚲 Browse bikes with filtering by type
- 🔍 Search bikes by name
- 📅 Online booking system
- 💳 Multiple payment options
- 📱 Fully responsive design
- 📧 Contact form

### Admin Features

- 🔐 Secure login system
- 📊 Dashboard with statistics
- ➕ Add/Edit/Delete bikes
- 📋 Manage bookings
- 💬 View contact messages
- 🖼️ Image upload functionality
